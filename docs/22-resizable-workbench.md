# 工作台区域大小调整

左侧栏右边界、检查器左边界、底部面板上边界均可拖动。边界有 8px 命中范围，悬停、键盘聚焦和拖动时显示强调线。编辑区域随相邻面板变化自动分配剩余空间。

- 鼠标或触摸拖动：即时更新尺寸；松开保存。
- 方向键：每次 8px；Shift + 方向键：每次 40px。
- Home / End：最小 / 最大尺寸。
- 双击或 Enter：恢复该区域默认大小。
- Escape、指针取消、捕获丢失或窗口失焦：取消当前拖动并恢复之前尺寸，不保存中间值。

默认侧栏 260px、检查器 360px、底部面板展开高度 240px。侧栏范围 180–480px，检查器 260–640px；实际最大值还会根据窗口限制，在空间允许时保留编辑器至少 320px 宽度和 200px 高度（窄屏优先保留 300px 高度）。收起底部面板后可从上边界向上拖动打开，展开后不能拖到低于最小可用高度；收起仍使用原有按钮。

尺寸以 `numen.workbench.layout.v1` 保存于当前站点 localStorage。窗口变小只调整实际显示尺寸，不覆盖用户偏好；关闭再展开面板、页面切换和刷新均复用保存的尺寸。保存内容只有尺寸，不含业务数据。存储损坏、禁用或写满时使用默认值并保留当次交互能力。

1280px 及以上检查器停靠；900–1279px 使用可调整宽度的浮层；小于 900px 保留移动端布局，侧栏隐藏、检查器固定为适合窄屏的抽屉，底部面板仍可调整。活动栏、顶部栏与状态栏保持固定。

`@numenjs/components` 导出不依赖 Workbench 的 `ResizeHandle`。工作台通过 `workbench-layout.ts` 管理尺寸与存储，通过 `PanelResizeHandle` 统一普通页及自动化页的底部行为。已有 Page Chrome 插件继续使用原有区域约定；插件自己的分栏可直接使用 ResizeHandle，自行管理布局和保存位置。

验证覆盖：尺寸组合边界、损坏偏好、实际鼠标拖动、键盘微调、刷新恢复、页签/页面切换、草稿内容保留、停靠与浮层切换、窄屏、Escape/指针中断，以及存储不可用。
